# LanguageBot
## О проекте 
**LanguageBot** — Telegram-бот для изучения английской лексики. Здесь можно сохранять собственные словарные записи и тренировать их с помощью упражнений.
Проект разработан на C# с использованием .NET и SQLite в рамках учебного проекта на курсе C# basic в «».

## Возможности
- Добавление английских слов и словосочетаний с русским переводом.
- Просмотр сохранённых словарных записей.
- Редактирование и удаление записей.
- Тренировка лексики с помощью перевода и дополнения английских выражений.
- Хранение пользовательских данных и словарных записей в базе данных SQLite.

## Технологии
- Язык программирования: C#
- Платформа: .NET 8
- Telegram API: библиотека Telegram.Bot
- База данных: SQLite

## Архитектура
Приложение имеет несколько компонентов, каждый из которых отвечает за определённую часть логики.
- Обработчик обновлений (UpdateHandler) обрабатывает сообщения Telegram, команды и пользовательские сценарии.
- Сервисы (Services) — реализуют логику работы с пользователями и словарными записями.
- Репозитории (Repositories) — обеспечивают доступ к данным и их хранение в SQLite.
- Интерфейсы (Interfaces) — определяют контракты взаимодействия между компонентами.
- Модели (Classes) — представляют данные пользователей, словарных записей и состояние тренировочной сессии.

## Пользовательские команды: 
**/start**	- регистрация нового пользователя или отображение уже сохранённых записей для существующего пользователя.  
**/addphrase** - добавление английской словарной записи и русского перевода.  
**/edit** - редактирование существующей словарной записи.  
**/removephrase** - удаление существующей словарной записи.  
**/show** - выводит список всех словарных записей пользователя.  
**/practice** - запуск тренировки по сохранённым словарным записям.  
**/stop** - остановка тренировки по сохранённым словарным записям.  
**/help** - получение краткой справки о работе бота.  
**/info** - просмотр информации о боте.  

Чтобы добавить словарную запись, необходимо ввести английский текст и русский перевод через запятую. Например: take part, участвовать.  
В режиме тренировки бот предлагает задания по сохранённым записям. Для некоторых заданий требуется перевести слово, для других — дополнить английское выражение. В рамках одной попытки на задание предусмотрено до трёх попыток ответа. Если пользователь трижды вводит неправильный ответ, бот выводит сообщение о том, что попытки закончены и показывает правильный ответ.
